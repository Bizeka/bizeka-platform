# Changelog

## 0.1.3-alpha - 2026-11-16

- Release: first public release under the MIT license (owner decision 2026-11-16). Packages declare `MIT`, npm manifests are no longer private, SourceLink metadata is published, and a tag workflow attaches the NuGet and npm archives to the GitHub Release. README, SECURITY and SUPPORT are rewritten for public use.
- Serenity 10.6.3: Serenity NuGet packages, Sergen, `@serenity-is/*` npm packages and `@serenity-is/tsbuild` move from 10.5.2 (tsbuild 10.4.0) to 10.6.3, TypeScript from 5.9 to 7.0.2 (ADR 0003). ImageSharp is no longer in the dependency graph, so its five audit suppressions are removed and the strict dependency audit passes; hosts supply SkiaSharp. `Size(-1)` is removed from the JSON text fields of DynamicForms, Extensions and Todo (Serenity 10.6 rejects negative sizes). Demo and OnlineChat tsconfig files drop `baseUrl` and set `rootDir` for TypeScript 7. Regenerated server types add `Namespaces.ts` and `undeletePermission`. Microsoft.Data.Sqlite and System.Security.Cryptography.Pkcs 10.0.14, Microsoft.NET.Test.Sdk 18.12.0. Consuming hosts must be on Serenity 10.6.3.
- Theme: the component contract test reads the system dark-mode block by its current selector (`:not([data-bizeka-mode="light"]):not([data-bizeka-mode="dark"])`).
- Theme: the Dynamic Forms field list stays inside the form on phones and starts in line with the inputs; the table scrolls sideways inside it.
- Theme: on phones the rows of a full-page grid scroll inside the grid, with the toolbar and pager in view; rows below the screen could not be reached before. The page stays fixed to the screen, which differs from Serene's default, where a phone page scrolls.
- Demo: every sample page is in one language, Turkish or English, including headings, sample data, buttons and notifications; introductions are one short paragraph. Mode and Accent reports the theme in a sentence and follows the header menu; Design Tokens has an index, a search box and live values.
- Extensions: `addGridEmptyState` shows a message in a grid with no rows; `ColoredColumnFormatter` picks readable text for a hex background (pale colors were unreadable in dark mode); `MonthYearFormatter` uses the month names of the page language; `TagListEditor` and `NumericStepperEditor` translate their labels; `BooleanSwitchEditor` and `NumericStepperEditor` inputs take the field caption as their accessible name.
- OnlineChat: on phones a conversation fills the screen below the header, and the message box is one plain field. The room search works, rooms are reachable by keyboard, an empty list shows a message, and phones have one back button. A user no longer gets a notification about their own presence, and presence notifications show the display name instead of the user id (`IOnlineChatClient.UserPresenceChanged` takes the name). A refused connection no longer counts as the user going offline.
- Todo: the task list shows a message when it has no rows; the priority and status page titles are translated.
- Theme: `bizeka-theme-init.js` applies the saved mode and accent before the first paint; a saved dark mode flashed light on every page because `initBizekaTheme()` runs from a deferred module. Hosts add the script to `<head>` (`docs/host-integration.md`).
- Theme: the sidebar menu scrolls inside its pane; `initBizekaTheme()` applies the saved mode, follows the operating system in system mode and adds a light / dark / system menu to the Serene header; `services.AddBizekaTheme()` registers the theme as an application part so its texts load. Checkboxes no longer stretch across a form field, unchecked boxes have a visible edge, and the Dynamic Forms field dialog uses the standard control size.
- Extensions: `ColorHexEditor` and `ColorPickerEditor` add a free color picker next to a bordered hex box, the preset palette and recent colors; `CheckboxButtonEditor` spaces its options; `addGridFilterToggle` adds a Serenity toolbar button with a localized label; the tag editor button uses the theme accent.
- Demo: a sample can show module sources next to its page; the Online Chat sample shows the hub, the client connection and the host wiring first. Sample grids grow with their toolbar and quick filters, so the pager stays inside the card on phones and desktops.
- Documentation: `docs/host-integration.md` walks through adding each module to a Serene 10.5.2 host.
- Theme: in dark mode Bootstrap's subtle colors (`--bs-*-bg-subtle`, `-border-subtle`, `-text-emphasis`) follow the dark surface and text, so alerts such as `.alert-info` are no longer light; the component contract checks both dark blocks.
- Extensions: the `PhoneEditor` validation texts move from `Validation.NorthwindPhone` and `Validation.NorthwindPhoneMultiple` to the module's own `Validation.Bizeka.Phone` and `Validation.Bizeka.PhoneMultiple`, so they no longer share keys with the Northwind sample; `ExtensionsValidationTexts` now points to `Texts.Validation.Bizeka`. Hosts that translated the old keys rename them.
- OnlineChat: Enter sends the message (the input listened to the deprecated `keypress` event, which some input methods do not fire); Enter that confirms an IME composition does not send.
- Documentation: module READMEs and the Todo architecture notes describe features outside a module's scope without naming a product; the contributing rules no longer name the commercial repository.
- Tooling: the text-template generator loads each module from its own build output in an isolated load context and references only Serenity; it no longer reads stale module copies from its own output after a single-module build.
- DynamicForms: Vitest setup with a test that `DynamicFieldsEditor` keeps HTML in field names, captions and types as text; esbuild 0.28.2 (required by Vitest 5). CI runs it after the Extensions tests.
- Demo: rebuilt as a BasicSamples-style showcase with 15 samples in six categories (`~/Demo/<Sample>`, menu **Bizeka Samples**), a shared layout and the sample source shown next to each sample. The previous `~/Demo/ExtensionsOverview`, `DynamicFormsSample`, `TodoSample`, `OnlineChatSample` and `ThemeSample` routes are removed.
- Extensions: the npm entry exports every formatter and `StaticTextBlock`; `PhoneFormatterAttribute` is added. Fixed: `PhoneEditor` rejected every valid number (its rule returned an empty string, which the validator counts as an error) and showed "undefined" for a missing value; `EmptyLookupEditor` threw because it looked up a script that does not exist; `FontColorColumnFormatter` ignored the `ColorProperty` and `Color` options of its attribute; `MonthYearFormatter` required a `Months` enum that no module registers.
- Dependencies verified locally: @microsoft/signalr 10.0.11 (OnlineChat), esbuild 0.28.2 (OnlineChat, Theme), jsdom 30.1.3, Microsoft.Data.SqlClient 7.1.1, Microsoft.Data.Sqlite 10.0.13, Microsoft.NET.Test.Sdk 18.11.0, Moq 4.21.0. Dependabot no longer proposes Sergen or TypeScript major versions; both move with the coordinated Serenity upgrade (TypeScript 7 removes `baseUrl`, which the Serenity tsconfig layout uses).
- OnlineChat: clients can no longer write `FileUrl` or the delete stamps; messages are plain text, required and at most 4,000 characters; a per-user send limit (default 30 per minute, `OnlineChatSignalR:MessagesPerWindow` and `SendWindowSeconds`) rejects flooding; the panel no longer turns text into links or images. `ChatMessageDto.FileUrl` and `NormalizedChatMessage.fileUrl` are removed.
- DynamicForms: the definition lookup moves to `DynamicFormDefinitionLookup` and returns active definitions only; inactive definitions were still applied to dialogs. The Northwind example definition moves to `Bizeka.Demo` (migration `20261022_1200`); product installations get no demo data.
- Theme: the page bundle is packed at `_content/Bizeka.Theme/esm/Modules/index.js` instead of a doubled `esm/esm` path.
- Generated `wwwroot/esm` bundles are no longer committed; the package check requires every built bundle in the archive, and CI fails when a build changes tracked files.
- TypeScript strict mode in every module (`noImplicitAny` off where Sergen generates untyped service callbacks).
- Tooling: the Windows package-consumer restore fix, a repository-guard platform check independent of the folder name, Dependabot ignoring Serenity and FluentMigrator, the host contract, issue and pull request templates, and CODEOWNERS.
- Tests for OnlineChat safety and hub permission, per-module installation on every provider, demo-data isolation, migration version uniqueness and the active-only lookup.

- Remove the OnlineChat attachment button and incomplete temporary-upload trigger; document text-only message composition.

- Pin transitive System.Security.Cryptography.Pkcs to 10.0.13 to address the two advisories affecting 10.0.0.
- Update the frontend test runner and its esbuild prerequisite; retain frozen npm installs and restore NuGet-provided runtime files afterwards.
- Prepare accurate private prerelease archives with repository URLs, license and third-party notices, and remove developer configuration from NuGet consumer content.
- Add repeatable dependency installation, package-content verification, strict release dependency audits, and release/security documentation.
- Stabilize DynamicForms generation by keeping its public package barrel outside Sergen's module input tree, and remove the vacuous Theme backend test project; the existing theme contract/contrast/visual suite remains the meaningful theme check.
- Record the owner's Oracle deferral and coordinated Serenity 10.6.0/ImageSharp-to-SkiaSharp upgrade plan; no framework upgrade is included here.

No public release has been declared. These changes do not certify deployment safety or satisfy the external public-release requirements.
