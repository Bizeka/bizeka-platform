# Support

Bizeka Platform `0.1.3-alpha` is an alpha release supported on a best-effort basis.

- **Questions and bugs:** open a [GitHub issue](https://github.com/Bizeka/bizeka-platform/issues/new/choose) with the module, version, Serenity version and a minimal reproduction.
- **Security vulnerabilities:** never in a public issue; follow [SECURITY.md](SECURITY.md).
- **Other contact:** platform@bizeka.com.

Read [README.md](README.md), the [host integration guide](docs/host-integration.md) and the [host contract](docs/host-contract.md) first. Serenity framework questions belong to the Serenity project.
